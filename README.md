# Aventura en el Bosque

## 1. Descripción del proyecto

Aventura en el Bosque es un videojuego de plataformas 2D desarrollado como proyecto académico para la Fase 3 del curso Programación para Videojuegos de la Universidad Nacional Abierta y a Distancia (UNAD).

El juego presenta a Leo, un personaje que explora un bosque para encontrar su mochila perdida. Durante el recorrido, el jugador podrá superar obstáculos, saltar entre plataformas, recoger residuos y contribuir a la recuperación de algunas zonas naturales.

El proyecto busca integrar mecánicas de juego, elementos artísticos y sonoros, y criterios de accesibilidad para ofrecer una experiencia comprensible y entretenida.

## 2. Objetivo del videojuego

El objetivo principal es explorar el bosque y recuperar la mochila de Leo. Las acciones de cuidado ambiental son opcionales y ofrecen recompensas, sin impedir que el jugador complete el objetivo principal.

## 3. Mecánicas previstas

- Movimiento del personaje: caminar y correr.
- Salto para superar obstáculos y plataformas.
- Exploración del escenario.
- Recolección opcional de residuos.
- Interacción con zonas naturales para contribuir a su recuperación.
- Sistema de puntos y un indicador de cuidado ambiental.
- HUD con información relevante para el jugador.

Estas mecánicas se incorporarán y verificarán durante el desarrollo.

## 4. Herramientas de desarrollo

- Unity Editor 2022.3.62f2.
- Plantilla 2D (Built-In Render Pipeline).
- Git y GitHub Desktop para el control de versiones.
- GitHub para alojar el repositorio y compartir los avances.

## 5. Accesibilidad

Durante el desarrollo se tendrán en cuenta criterios de accesibilidad, entre ellos:

- Contraste adecuado entre los elementos visuales.
- Textos legibles e instrucciones claras.
- Información importante comunicada mediante señales visuales y, cuando corresponda, sonoras.
- Alternativas visuales para las señales de audio relevantes.
- Revisión de criterios aplicables de WCAG 2.2 y principios de Diseño Universal para el Aprendizaje (DUA).

La implementación y verificación de estas medidas se documentará durante el proyecto.

## 6. Estructura del repositorio

- `Assets/`: escenas, scripts y recursos del videojuego.
- `Packages/`: configuración de paquetes de Unity.
- `ProjectSettings/`: configuración del proyecto.
- `.gitignore`: reglas para excluir archivos temporales y específicos del entorno local.

## 7. Requisitos para abrir el proyecto

1. Instalar Unity Hub.
2. Instalar o utilizar una versión compatible de Unity Editor. El proyecto se creó con Unity 2022.3.62f2.
3. Clonar o descargar este repositorio.
4. Abrir Unity Hub y seleccionar **Add** o **Open** para localizar la carpeta del proyecto.
5. Abrir el proyecto y esperar a que Unity importe los recursos.
